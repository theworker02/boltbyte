# boltbyte

Bolt config/byte key checks for twelve-factor services.

**Site:** https://theworker02.github.io/boltbyte/

## Install / run

```bash
git clone https://github.com/theworker02/boltbyte.git
cd boltbyte
node src/cli.js
node --test
```
